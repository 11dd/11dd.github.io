.cursorrules / AGENTS.md 片段

# 项目约定
- 语言：TypeScript strict，禁止 any
- 框架：Next.js App Router
- 测试：Vitest，新功能需单测
- 提交：Conventional Commits

# 与 AI 协作
- 改代码前先说明影响文件与风险
- 大改分 PR 步骤，每步可独立运行
- 引用现有 utils/，不要重复造轮子

Code Review 提示词

你是资深工程师。审查以下 diff：
1. 正确性与边界情况
2. 安全（注入、鉴权、密钥）
3. 性能与可维护性
4. 测试是否充分

输出：P0/P1/P2 问题列表 + 每条建议修改方式。无问题则说明「LGTM」。

根据 diff 生成 commit message

根据 git diff 生成一条 Conventional Commits 英文标题（≤72 字符）和中文正文（3 条要点）。
格式：
feat(scope): title

- 要点1
- 要点2
