# 视觉检测能力展示

这是一个用于技术展示的静态展示页，不需要后台和构建工具。

## 打开方式

直接双击 `index.html`


## 内容定位

网站内容按“行业洞察 → 行业痛点 → 发展判断 → 解决方案 → 项目案例（缺陷示例）→ 项目流程（八阶段时间线、报价拆分、标准交付模板与证据链）→ 指标体系（含硬件标准化与光学/EMC 验收）→ 实施运维（含运维数据与故障分流）→ 系统架构 → 算法链路 → 参数体系 → 工业集成（含工程模块映射与产线工程拆解）→ 开发手册 → 开发总结 → 资料入口”组织，重点展示：

- 行业前景：整理工业外观缺陷检测的高需求行业、刚需梯队、国内外代表企业和市场机会。
- 公司业务能力：补充公司定位、玻璃外观缺陷在线检测设备、技术服务、一站式解决方案、售后支持和行业案例方向。
- 综合能力矩阵：把业务能力、项目案例支撑、代码技术证据和交付管理能力对应起来，形成完整的能力证明链。
- 发展判断：说明公司从项目制交付走向标准化产品的必要性，分析硬件、开发、实施、差旅、售后等成本项对项目收益的影响。
- 规模化方案：总结成熟企业常用的硬件配置包、软件平台、行业模板、实施 SOP、售后维护和复购模式。
- 项目案例：项目目录卡片、典型缺陷类型与判定卡片。
- 项目流程：八阶段时间线、报价与交付单元拆分、标准交付模板与证据链要求（交付物清单与三栏管控要点）。
- 指标体系：验收口径（质量/节拍/稳定/追溯）与硬件模组选型、光学验证、电气与 EMC 验收清单。
- 实施运维：现场管控与确认项、运维与数据闭环、故障分流树（已与实施合并呈现）。
- 资料入口：整理外部官方资源入口（相机/光学/3D、视觉软件、AI 推理、PLC 协议、数据库、.NET 组件等），用于 SDK 下载与技术文档查询。
- 已覆盖的检测项目：家电玻璃丝印、玻璃深加工、碳纤维板材、铜材、医疗管材、投影/曲率检测、光检机 TensorRT。
- 公司案例对应：补充玻璃、新材料、汽车制造、医疗耗材、电子、半导体、液冷散热等案例方向与检测项目沉淀的对应关系。
- 方案导读：用一块产品从进入设备到输出 NG 的完整流程解释相机、光源、算法、PLC、数据库之间的关系。
- 系统架构：成像与触发、采集队列、AI 检测、传统视觉复核、规则判定、产线闭环。
- 算法链路：图像预处理、大模型候选定位、小模型分类复核、丝印专项差异检测、缺陷尺寸量化、结果合并。
- 可检测的缺陷类型：丝印暗点、亮点、白边、漏印、玻璃区暗点、锯齿、水渍、划伤、崩边、污渍、分层、色差、毛边、皱纹等。
- 缺陷字典（已合入开发手册）：统一模型标签、中文名、缺陷值定义、阈值字段、优先级、是否参与 NG 与追溯字段，支撑跨项目复用与验收解释。
- 故障分流树：已并入「实施运维」章节，按无图/成像/召回/分类/阈值/PLC/追溯/性能分流并列出证据要求。
- 参数体系：模型配置、缺陷阈值、视觉测量参数、产线运行参数。
- 工业集成：相机至产线闭环的现场集成要点，并包含工程模块映射（代码职责）与硬件/产线工程拆解（精度、工控配置、M01–M12）。
- 开发手册：按产品开发路径细化开发语言、必备技能、整体开发思路、流程模块拆分、项目接手、核心数据流、新增缺陷、新模型接入、参数调试、相机接入、项目配置、PLC/IO 联动、数据库追溯、部署守护、开发验证和现场联调故障排查。
- 开发总结：说明同行主流做法不是完全标准品也不是完全项目制，而是通过平台内核、行业模板、硬件配置包、样本数据闭环和实施 SOP 提升复用率，并结合当前代码提出优化路线。

## 文件说明

- `index.html`：页面结构和技术培训内容。
- `styles.css`：视觉样式，工业科技风。
- `script.js`：导航、筛选、折叠面板、参数切换交互。
