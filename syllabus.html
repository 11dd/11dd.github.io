🔄 典型数据流
  1. 用户提问 → 网关鉴权、限流
  2. （可选）RAG：检索文档块 → 拼入 Prompt
  3. （可选）Agent：模型调用工具（API/数据库）
  4. 调用大模型 → 流式返回
  5. 内容安全、脱敏、观测落库
💡 多数企业场景：云 API + RAG 即可 MVP；全参微调多为后期优化。
🌳 技术选型决策树
要引用内部文档？
是 → RAG；否 → Prompt + API。
要操作外部系统？
是 → Agent + MCP，权限最小化。
要固定话术/格式？
先 Prompt；不够再 LoRA。
数据能否出网？
不能 → 私有化 + 国产/开源模型。
📦 三种落地模式
模式适用组件复杂度
对话助手客服、问答Dify + 向量库低
知识 Copilot法务/研发文档RAG + 溯源 + 分库权限中
自动化 Agent跨系统流程LangGraph / n8n + MCP高
